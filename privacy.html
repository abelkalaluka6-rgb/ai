Privacy information

This page explains how the current AAK AI web application handles information. AAK AI is an independent product and is not part of the Kambule school website.

1. Accounts and conversation synchronisation

When cloud accounts are configured and you sign in, conversation records are stored in the AAK AI Supabase database and associated with your account. Row Level Security policies restrict each account to its own conversation rows. A local browser copy is also kept to support the interface and offline continuity. Signing in on another device retrieves your cloud-synchronised conversations. If you use AAK AI without signing in, conversations remain in that browser only.

2. AI processing

When you send a message, the message and the recent conversation context are sent to the AAK AI server function hosted by Cloudflare. If you attach an image or PDF, its contents are also forwarded to Google's Gemini API for analysis. The current interface accepts JPG, PNG, WebP and PDF files, up to four files and 4 MB combined per message. The file contents are not stored in AAK AI chat history; attachment names and file types may be retained with the conversation. The server function forwards the request to Google's Gemini API to generate a response. The Gemini API key is stored as a server-side Cloudflare secret and is not intended to be exposed in the website code.

Google processes submitted content under the terms, settings and data policies applicable to the Gemini API project and API key. Review Google's current Gemini API terms and data use information before using the service.

3. Voice input

If you use the microphone button, your browser may use its speech-recognition service to convert speech into text. The browser or its speech provider may process audio under its own privacy terms. AAK AI receives the recognised text only after you send your message. Microphone access is requested by the browser and can be revoked in browser settings. Voice input availability depends on the browser, device and supported language.

4. Account information and service providers

Account registration, sign-in, email confirmation and password recovery are handled by Supabase Auth. Conversation content is stored in the Supabase database when cloud sync is enabled. Supabase processes account and database information under its applicable terms and privacy documentation. AAK AI does not store users' raw passwords. The browser configuration contains only the Supabase project URL and public publishable key; privileged service-role keys must never be placed in client code.

5. Local copies, sign-out and deletion

A local copy of recent conversations may remain in the browser used to access AAK AI; this local copy is stored by the browser and is not encrypted by the AAK AI application. Signing out does not delete cloud conversations. Account deletion is not yet self-service in this release. Users will need to contact the service operator for account deletion and data requests. Before public launch, the operator must publish a monitored support contact and define a retention and deletion process.

6. Information you should not submit

Do not send passwords, API keys, financial account credentials, confidential business information, sensitive personal information or information you are not authorised to share. AI-generated answers may be inaccurate; independently verify important decisions.
